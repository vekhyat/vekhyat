### Selected work

<a href="https://github.com/vekhyat/SatQuery-AI"><img src="https://raw.githubusercontent.com/vekhyat/vekhyat/main/assets/satquery.svg" width="400" alt="SatQuery AI. ISRO problem statement. Team prototype. Python, FastAPI, React." /></a>

**[SatQuery AI](https://github.com/vekhyat/SatQuery-AI)**
Team project for an ISRO problem statement. Upload a satellite image, ask a question, and a rules router picks one of three workflows. The answer comes back with the raster evidence. Change detection uses a pretrained model. The repo does not include training or a deployment.

<a href="https://github.com/vekhyat/Auralis"><img src="https://raw.githubusercontent.com/vekhyat/vekhyat/main/assets/auralis.svg" width="400" alt="Auralis. Lossless audio from a Spotify link. Go, TypeScript, Wails." /></a>

**[Auralis](https://github.com/vekhyat/Auralis)**
Desktop app. Paste a Spotify link or a search, then download a lossless file from Tidal, Qobuz, Amazon Music, Deezer, Apple Music, or JioSaavn.
